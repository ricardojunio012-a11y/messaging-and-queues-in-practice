# Messaging and Queues in Practice: lab code

Lab code for the book *Messaging and Queues in Practice*, by Ricardo Júnio Gonçalves Filho (In Practice collection).

Each chapter has its own folder in `code/chNN/`, with a `README.md` that walks through the lab. The labs run with Docker and Docker Compose; the AWS labs use LocalStack, with no cloud account. Appendix A of the book explains how to set up the environment.

The `.env` files hold only lab settings and lab passwords, for local use.

Found a mistake in the book or the code? Open an issue or write to ricardojunio012@gmail.com.
